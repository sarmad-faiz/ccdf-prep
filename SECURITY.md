# Security policy

Please report security problems privately via a [GitHub security advisory](../../security/advisories/new), not a public issue.

Especially interesting:

- Any way to read answer keys or explanations before answering or finishing (they should only leave the database through the grading functions).
- Reading or changing another user's progress.
- Bypassing the exam timer, or claiming an email address without verifying it.
- Leaked keys or secrets in the repository.

Please include steps to reproduce. You'll get a reply as soon as possible, and credit in the fix if you'd like it.
